# Bhishan Rai — Personal Portfolio

Dark & elegant single-page portfolio template.

## How to use

1. Open `index.html` in a browser (or serve the folder with any static server).
2. Replace all placeholder text with your real content:
   - Hero subtitle
   - About section (bio + meta)
   - Skills lists
   - Project titles, descriptions, and images
   - Blog/journal posts
   - Contact email, LinkedIn, and resume link
3. Swap the image placeholders with your photos (or keep the elegant dark cards).

## Design notes

- **Palette**: Near-black backgrounds, warm off-white text, soft gold accent (`#c9a962`)
- **Typography**: Cormorant Garamond (serif headings) + Outfit (sans body)
- **Style**: Bold elegant, refined, minimal ornament
